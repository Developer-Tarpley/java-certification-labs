# Java Certification Labs

This repository contains my structured Java learning work completed while studying for the IBM Java certification.  
It includes foundational exercises, practice labs, small projects, and hands‑on code that helped me build confidence with Java fundamentals and object‑oriented programming.


## 📁 Repository Structure

This repository is organized by individual labs completed during the IBM Java certification:

- **lab01-first-program/** — basic Java syntax, printing, and program structure  
- **lab02-data-types/** — primitive types, type conversion, and basic operations  
- **lab03-operators/** — arithmetic, logical, and comparison operators  
- **lab04-arrays-loops/** — arrays, iteration, and loop-based logic  
- **lab05-strings/** — substring logic, parsing, and character processing  
- **lab06-functions-methods/** — custom methods, parameters, return values  
- **lab07-exception-handling/** — try/catch, error handling, and input validation  
- **lab08-grocery-shop/** — final project: a simple grocery store application
